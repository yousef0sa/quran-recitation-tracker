# Security policy

## Reporting a vulnerability

Please report security and privacy issues privately, not in a public issue:
open the repository's **Security** tab and choose **Report a vulnerability**.

This is a one-person open-source project, so replies are best effort.

## What counts

The app runs fully in the browser, on the user's device. Audio and user data must
never leave the device. Please report anything that breaks this, for example:

- audio, recordings or other user data sent over the network;
- a dependency or script that phones home or adds tracking;
- a way for one site or user to read another user's data;
- secrets, recordings or model files committed to the repository.

Wrong tracking results are not security issues: open a normal issue for those.
